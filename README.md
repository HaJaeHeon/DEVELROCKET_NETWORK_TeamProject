## 3. 핵심 플레이 흐름 (로그인 → 로비 → 게임 → 결과 → 재대전)

<img width="579" height="822" alt="NetworkTeamDiagram drawio (2)" src="https://github.com/user-attachments/assets/9f0dbdc8-7b19-44cc-a6fb-7b8a01c90e37" />

1. 타이틀 씬에서 회원 가입 및 설정 후,  로그인 하면 로비로 입장
2. 현재 방 목록 중에서 원하는 방 입장하거나, 랜덤 룸 입장, 방 만들기를 통해 방에 입장, 타워 프리셋 설정
3. 방에서 서로의 타워 프리셋을 확인하고 준비가 완료되면 준비 완료 버튼을 눌러 ‘준비 완료’ 상태에 진입 / 방장이 모든 플레이어(방장 포함)가 ‘준비 완료’ 시 게임을 시작함 >> 게임 Scene으로 이동
4. 게임 Scene에서 게임 진행
5. 결과 ( Clear / Lose ) 에 따라 DB에 게임 결과 내용이 저장됨 ( Clear 시에만 저장되며 게임 점수, 같이 플레이한 플레이어 목록)
6. 결과 확인 후 모두 방으로 돌아옴
7. 방을 나가거나 다시 게임을 시작

## 6. 동기화 설계표 최종본 (기능 / 동기화 대상 / 방식 / 판정 권한 / 실패 시)

| 기능 | 동기화 대상 | 방식 | 판정 권한 | 실패 시 |
| --- | --- | --- | --- | --- |
| 타워 프리셋 설정 | 타워 프리셋 목록 | Player Custom Properties // 타워 프리셋의 Form에 맞게 저장 요청 확인 → DB저장 | 각 플레이어 자기 자신 | 플레이어가 준비 상태로 넘어갈 수 없음 / 프리셋 오류 알림 |
| 플레이어 준비 상태 | 각 플레이어 준비 상태 여부 | RPC // 상태 변경 요청 → 확정된 상태 를  방 전체 플레이어에게 전달 | 서버(Host) | 기존 상태 유지 / 실패 알림 |
| 게임 시작 | 게임 시작 여부 | Raise Event // 방 전체 플레이어 모두 준비 완료 상태이면 → 게임 시작 알림 전달 | 서버(Host) | 게임 시작 Reject / 실패 알림 |
| 적 위치 | 적 Transform | Photon View Transform | 서버(Host) | 적 위치 보간 |
| 적 애니메이션 | 적 Animator | Photon Animator View | 서버(Host) | 다음 동작 진행  |
| 적 피격 | 적 HP | RPC // 해당 적 HP 감소 알림 | 서버(Host) | 재전송 요청, 최신 상태로 복구 |
| 타워 공격 모션 | 타워 Animator | Photon Animator View | 서버(Host) | 다음 동작 진행 |
| 타워 건설 | 타워 Object, PhotonView Ownership | RPC // 타워 건설 요청 → 해당 위치에 건설 가능 여부 판단 → 타워 건설 | 서버(Host) | 재전송 요청, 이미 다른사람이 지었으면 재화 반환 |
| 타워 철거 | 타워 Object, PhotonView Ownership | RPC // 타워 철거 요청 → 해당 플레이어 소유 검사 → 타워 철거 | 서버(Host) | 재전송 요청, 철거 된 상태면 오브젝트 반환, 철거 안된 상태면 현 상태 유지 |
| 플레이어 마우스 위치 | 마우스 Image 오브젝트 | Photon Transform View | 서버(Host) | 플레이어 마우스 위치 보간 |
| Life 감소 | 공동 Life | Room Custom Properties // 적이 목적지 도달 시 감소 | 서버(Host) | 최신 Life로 복구 |
| 웨이브 진행 | 현재 Wave 진행 단계, 다음 웨이브까지 준비 시간 | Room Custom Properties // 서버(Host)가 남은 적 없을 시 다음 웨이브까지 남은 시간 표기 후 다음 웨이브 진행 | 서버(Host) | 가장 최근 Wave 를 Load |
| 게임 종료 | 게임 결과 | Room Custom Properties // 게임을 종료 시키고 RoomScene으로 복귀 | 서버(Host) | 게임 종료 수신 확인, 일정 시간 후 방으로 귀환 |

## 8. 실패 상황 처리 목록 (접속 끊김 · 방장 이탈 · 늦은 입장)

- 접속 끊김 :
    - 재접속 시도 , n회 시도 후에도 접속 안되면 연결 끊김 알림 / 방에 재입장 불가 / 가지고 있던 건물은 모두 철거하고 남은 재화는 현재 방에 남아 있는 모든 플레이어에게 n등분 해서 나눠줌
- 방장 이탈 :
    - 가장 우선순위 높은(핑이 제일 좋다거나 들어온 순서가 가장 빠르다거나) 클라이언트에게 Host와 방장을 넘김 / 다른 클라이언트가 존재하지 않을 시 방 해체
- 클라이언트(방장이 아닌 다른 모든 플레이어) 이탈 :
    - 재접속 시도, n회 시도 후에도 접속 안되면 연결 끊김 알림 / 재입장 불가 / 가지고 있던 건물은 모두 철거하고 남은 재화는 현재 방에 남아 있는 모든 플레이어에게 n등분 해서 나눠줌
- 늦은 입장 :
    - 늦은 입장 불가

## 10. 팀원별 책임 영역과 기여 내용

### 하재헌

- UI
    - Title [ 로그인, 회원가입, 설정, 나가기 ]
    - Lobby [ 로그아웃(Title로), 타워 프리셋 설정, Room List, Player List, 방 검색, 선택한 방 입장, 랜덤 방 입장, 방 만들기 ]
    - InGame [ 전체 Life, 개인 재화, 개인 타워 프리셋, 몹 Spawn 위치, 몹 목적지 ]
- 사운드
    - 배경 음악
    - 버튼 클릭
    - 몬스터 죽는 소리, 타워 공격 소리
- 게임 시작 전 세팅 파트
    - 타워 프리셋, 설정 제작
- 플레이어 상호 작용
    - 맵 정보 확인, 타워 건설 가능 지역 확인, 타워 건설

### 권민수

- 타이틀
    - Photon으로 로그인(로비 입장), 회원 가입
    - Firebase DB로 회원 정보 등록, 회원 정보 일치하는지 확인
- 로비
    - Photon으로 로그아웃(Title로 나가기), 방 검색, 방 입장, 방 만들기
    - Firebase에 Preset등록
- 계정 (로그인, 회원가입, 프로필 정보- FIrebase DB)
- 맵 ( 전체적인 맵 생성, 타워 건설 가능 구역 설정, 적 이동 경로,  적 Spawn위치 설정, 적 목적지 설정)

### 권혁찬

- 타워
    - 행동 패턴
    - 코스트, 사거리, 데미지 등 데이터 작성
    - 데이터 및 오브젝트 프리팹 컨테이너 클래스 작성
    - 타워 및 탄환 오브젝트들 네트워크 동기화
- 적
    - 행동 패턴(길찾기)
    - 체력, 이동속도, 제공 보상(골드) 등 데이터 작성
    - 데이터 및 오브젝트 프리팹 컨테이너 클래스 작성
    - 적 위치 및 행동 양식 네트워크 동기화
- 스테이지 관리자 (웨이브 정보, 게임 루프)
